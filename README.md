# TESTAPPLICATION

Este es aplicación sencillo en donde estoy probando la libreria Flet de python

## 🚀 Como ejecutar la aplicación

a) Si tienes instalado **UV**<br>


    uv run src/main.py

Al ejecutarlo con UV se crea automaticamente el .venv con las dependencias necesarias.

b) En caso de no tener **UV** realiza la instalación de las dependencia que necesita la aplicación.


    pip install flet[all]

Hasta los momentos solamente esta flet instalado
